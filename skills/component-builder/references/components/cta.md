# Call To Action

## Responsibility

A call to action presents a clear next step at a decision point. It combines an action control with only the context needed to understand its value and consequence.

## Decisions

Choose the action, destination, commitment level, supporting proof, and whether a secondary path is genuinely needed. Match the CTA to the page stage rather than repeating the same conversion request everywhere.

## Constraints

- Use button semantics for actions and links for navigation.
- Labels must describe the result, not rely on vague text such as "Learn more" when a precise label is available.
- Do not promise access, pricing, or outcomes the destination cannot deliver.
- Keep one clear primary action within a CTA region.

## Verify

Check destination or action success, loading and failure, keyboard focus, analytics ownership, mobile fit, long translations, and consistency with surrounding claims.
