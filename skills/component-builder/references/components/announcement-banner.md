# Announcement Banner

## Responsibility

An announcement banner presents one timely, site-wide or section-wide message. It is distinct from field validation, an incident alert, and an evergreen promotional section.

## Decisions

Define audience, scope, message, action, start and end conditions, dismissal, persistence, and interaction with sticky navigation.

## Constraints

- Keep one primary message and one optional action.
- Do not use color alone to communicate severity.
- Dismissal persists only as long as appropriate.
- Avoid layout shift by reserving or consistently managing space.

## Verify

Check dismissal and reappearance, expiration, keyboard controls, translations, mobile wrapping, sticky stacking, and layout stability.
