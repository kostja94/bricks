# Top Banner

## Responsibility

A top banner presents one timely, site-wide or section-wide announcement above the primary content. It should communicate a material update without competing indefinitely with navigation.

## Decisions

Define audience, scope, message, action, start and end conditions, dismissal, persistence, and interaction with sticky navigation. Use it for announcements, incidents, deadlines, or offers with clear relevance.

## Constraints

- Keep one primary message and one optional action.
- Do not use color alone to communicate severity.
- Dismissal must persist only as long as appropriate for the announcement.
- Avoid layout shift by reserving or consistently managing its space.

## Verify

Check dismissal and reappearance rules, expiration, keyboard controls, long translations, mobile wrapping, sticky stacking, reduced viewport height, and layout stability.
