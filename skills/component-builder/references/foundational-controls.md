# Foundational Controls

Recognize Button, Link, Input, Textarea, Select, Checkbox, Radio Group, Switch, Slider, Label, Form, and closely related controls as components. Reuse the target project's established design system first, then a maintained accessible library. Build them from scratch only when the existing stack cannot satisfy the actual contract or the user explicitly requests a foundational implementation.

Do not create permanent catalog entries for visual variants such as Gradient Button or Glass Input. Separate entries are justified when the user task, interaction contract, HTML or ARIA semantics, data shape, or established discovery intent is materially different.
