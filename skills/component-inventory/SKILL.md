# Component Inventory

Read [the inventory workflow](references/workflow.md). Create or refresh the target project's component system document as a required deliverable, using [the document template](assets/component-system.template.md) as an adaptable starting point.

Inspect the actual source version and content. Cover page-to-component and component-to-page relationships, including inline blocks and dynamic gaps. A component directory listing is insufficient. Preserve an existing document location and project decisions; do not create a parallel inventory.

This is a source and content audit. Do not refactor or delete code. Record static reachability separately from observed rendering and production verification. Report document location, coverage, source version, and unresolved relationships.
